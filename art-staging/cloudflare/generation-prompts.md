# Cloudflare Workers AI UI prompts

Model: `@cf/black-forest-labs/flux-2-klein-9b`

Style reference for the UI frame and button: `public/assets/ui/new_gui/preview_2.png`

The first generation was rejected because its forest-green surfaces and bright ornament did not match the project's identity. The files currently referenced by the game are the neutral revisions below; earlier source outputs remain in this folder for history.

## Panel frame — 512 × 512

A single reusable ornate fantasy MMORPG window FRAME, 1:1 square image. Refined 16-bit pixel-art UI asset matching a somber ash fantasy RPG. Neutral palette ONLY: soot black, charcoal graphite, smoke grey, volcanic slate, restrained aged bronze and soft antique gold edge highlights. Absolutely no green, olive, emerald, teal, blue-green, neon, or purple. Thin clean dark iron outline, subtle ash-worn bevel, discreet bronze corner engravings. Large plain charcoal interior with no content. Symmetrical crisp pixel clusters, readable at 300px. The asset should feel restrained, worn and elegant, like a UI already belonging to the attached game art, not a new fantasy theme. No text, no letters, no icons, no extra objects, no outer glow, no cast shadow. Flat pure magenta #ff00ff outside the frame for transparency removal.

## Button frame — 512 × 256

One single wide rectangular blank game UI button, 3:1 horizontal composition. Restrained 16-bit pixel-art frame for a dark ash fantasy RPG, visually matching the attached grey iron and antique bronze UI sample. Neutral colours ONLY: near-black charcoal enamel, graphite, soot, very subtle ash grey highlight, narrow muted antique brass edge. Absolutely no green, olive, emerald, teal, blue-green, bright saturated jewel colors or neon. Compact beveled metal edge and simple corners, no elaborate ornaments, no glow. Empty dark interior, no text, no letters, no icon, no object outside the button, no cast shadow. Pure flat #ff00ff magenta background.

## Class-neutral player portrait — 512 × 512

Keep the same centered anonymous closed steel helm, charcoal hood, square portrait frame, silhouette and composition from the reference. Create the player portrait for a dark ash fantasy 16-bit pixel-art RPG. Change the forest-green cloak to charcoal-black woven fabric and soft ash-grey folds, with only a tiny restrained bronze clasp. Neutral dark graphite, soot, slate grey and muted brass palette. Absolutely no green, olive, emerald, teal, blue-green or neon anywhere. Preserve the helm, face coverage, mysterious identity and small-scale readability. Crisp compact pixel clusters, not photoreal. No weapon, no text, no letters, no extra objects. Flat pure magenta #ff00ff outside the portrait frame.
