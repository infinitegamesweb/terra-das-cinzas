# Tiles base dos biomas

Tiles de 32×32 px preparados a partir de `D:\Game\Assetsmaps\72ppi\Corrigidos_32x32`.

- `grass-base-32.png`: base vegetal para o Bosque das Ruínas.
- `snow-base-32.png`: textura da faixa nevada das Montanhas Rubras.
- `sand-base-32.png`: textura da bacia arenosa das Montanhas Rubras.
- `lava-rock-base-32.png`: rocha vulcânica usada nas regiões 3, 4 e 5.

O jogo espelha os tiles ao criar o padrão para suavizar as emendas. As imagens originais e a coleção organizada permanecem fora da pasta publicada.
