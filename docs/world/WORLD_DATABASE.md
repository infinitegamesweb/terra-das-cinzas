## 2. Inconsistências Mapeadas

1. **Catálogo de Thumbnails (`src/data/regionThumbnails.js`)**:
   - Possui mapeamento explícito de `0` a `12`.
   - Regiões `13` a `29` recorrem ao fallback (limitador `Math.min(12, ...)`).
   - **Solução Planejada (Fase 03 e 05)**: Expandir o catálogo para registrar as chaves `0` a `29` com fallbacks individuais sem travar o índice máximo no ID 12.

2. **Nomes nos Prompts vs Código**:
   - Região 05: Código usa "Trilha do Degelo"; prompts usam "Trilha do Dragão".
   - Região 07: Código usa "Portão Partido"; prompts citam "Portão Partido / Portão Petrificado".
   - Região 08: Código usa "Torre das Brasas"; prompts citam "Torre das Brumas".
   - **Regra**: Manter os nomes oficiais existentes em `src/systems/world/WorldMapManager.js` para não quebrar compatibilidade de saves.
